## 权威来源和边界

本次公开展示以用户提供的 `JEV_CachePlan_Beamer.tex` 与 **21 页 PDF 最终稿**为叙事依据，完整阅读规范、执行要求、汇报提纲，并逐页查看 PDF 渲染。数值以包内 CSV 与既有原始运行记录交叉核验；许可和源码归属保持真实。没有编辑该 Beamer 或原始实验数据，没有重新运行 GPU。

## 实验数字的完整精度口径

1. 核心中位加速：`415.0719844880514 / 48.99948832881637 = 8.470945282176539`。平均耗时另为 `415.26510919902165 / 48.98984407788763`，不能把这两个口径混写。
2. 拓展最长输入：`740.0075889801374 / 57.64764999237377 = 12.836734699125346`。
3. 核心实际缓存比：`1016928 / 1136750 = 0.8945924785572905`。97%只统计可复用字段值 Token，占比不含 JSON 键、模板和问题。
4. 扫描数：`2 × (3 + 2 + 2) = 14`；正式决策：`14 × 128 = 1792`，不含56次预热和3次缓存探针，不是14个数据集。
5. 7组配对各128条，共896对（1792个正式预测观测），预测一致、ID/概率/标签恢复完整；两个样例的概率允许变化。

全精度数据：[14轮CSV](../benchmarks/results/run_metrics.csv)、[公开汇总](../benchmarks/results/analysis_summary.json)、[本次只读核验摘要](presentation_evidence.json)。上传CSV的简化列名与公开版宽表逐轮对照一致；既有 `benchmarks/` 文件没有改写。
